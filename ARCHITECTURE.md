# NSE Industry Insights - Architecture & Context

This document provides a complete architectural overview of the NSE Industry Insights platform. It is designed to act as the primary context document for developers and AI assistants.

## 1. Project Overview
A highly interactive, institutional-grade market breadth and relative rotation (RRG) dashboard tailored for the Indian stock market (NSE). It parses pre-calculated historical and intraday financial data to render complex comparative tables, heatmaps, and tail-rotation graphs.

## 2. Technology Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (with arbitrary value overrides for exact hex colors)
- **Data Grids**: AG Grid (Community Edition)
- **Charting**: Plotly.js (via `react-plotly.js`) for complex scatter and RRG graphs.
- **Icons**: Lucide React
- **Persistence**: Browser `localStorage`

## 3. Data Architecture (Backend Pipeline)
This frontend **does not** fetch data live from APIs. Instead, it relies on static JSON and CSV files generated by an external Python data engineering pipeline.
- **`public/data/`**: Contains the output files.
- **`config.ts` / `types/index.ts`**: The schema and IDs in the TypeScript code must strictly match the output formats of the Python pipeline. If a ticker or category name changes in the Python pipeline, it must be updated in `lib/config.ts`.

## 4. Global Constants & Types (`lib/config.ts`)
We use a centralized configuration pattern to eliminate hardcoded strings. Always refer to `lib/config.ts` and `types/index.ts` for:
- `ThemeCategory`: `broad-market | sectors | industries`
- `QuadrantType`: `Leading | Weakening | Lagging | Improving`
- `TimeframeType`: `D | W | M`
- `TrendMetricType`: `momentum | ratio | both`
- `METRIC_CONFIG`: Central registry of all calculated return periods (e.g., "1D", "1W", "RS (5D)"). Any new column added by the backend must be registered here to appear in the UI.

## 5. State Management & Persistence
The dashboard leans heavily on the custom `useLocalStorage` hook (`hooks/useLocalStorage.ts`) rather than standard `useState` or global state libraries like Redux.
- **Why**: Financial dashboards are highly personal. If a user sets up a specific view (e.g., sorting the Jewellery sector by RS(20D) and hiding two columns), this state must be preserved across sessions.
- **How**: `useLocalStorage` wraps `useState` and intercepts updates to safely serialize and write the state to the browser's `localStorage` in real-time.

## 6. Key Components
- **`SectorRotationClient.tsx`**: Renders the Relative Rotation Graph (RRG). Includes a complex "Trend Scanner" that can iteratively check if historical tail points are rising/falling based on Momentum, Ratio, or Both.
- **`ThemePriceChart.tsx`**: A highly interactive price trend chart. Supports timeframe switching (D/W/M), custom technical indicators (SMA/EMA), and cross-theme comparisons normalized to percentage change.
- **`StocksMasterClient.tsx`**: A stateful master view of all configured themes. Includes granular stock-level filtering where a user can selectively uncheck constituents within a sector to isolate their view.
- **`PerformanceHeatmap.tsx`**: The main landing page grid aggregating all sectoral performances. Interacts heavily with AG Grid's column state API to save/restore layout changes.

## 7. Design Guidelines
- **Aesthetics**: Dark mode exclusive (`#0a0a0f` backgrounds). Borders are extremely subtle (`slate-800`).
- **Typography**: Small, dense, highly readable data fonts. Extensive use of uppercase tracking for labels.
- **Performance**: Large lists (like Constituents) rely on AG Grid's virtualization or `useMemo` hooks to prevent React render cycles from freezing the UI.
